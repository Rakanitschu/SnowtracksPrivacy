Security

Report a security issue

Security researchers and players can report vulnerabilities privately to the Snow Tracks developer.

Before publishing: Replace [SECURITY EMAIL] with a working contact address. Do not use a public GitHub issue to disclose exploitable vulnerabilities.

Responsible disclosure

Email [SECURITY EMAIL] with the affected app version, a description of the vulnerability, steps to reproduce, and its potential impact. Please avoid accessing other people's data, disrupting services, or publicly revealing exploitable details before coordinating a fix.

We aim to acknowledge valid reports and investigate them, but do not currently offer a bug bounty or guarantee a fixed response time.
